TCG Store

Descripción
TCG Store es un e-commerce desarrollado para la comercialización de Trading Card Game.
En esta primera etapa se construyó la estructura base de la aplicación utilizando componentes reutilizables, JSX, props y CSS.

Tecnologías utilizadas
React
Node js
Vite
JavaScript
CSS
React Icons
Git 
GitHub

Funcionalidades implementadas

Navbar

La barra de navegación incluye:

Nombre de la tienda: LS Store
Categorías de productos: Singles, Sellados y Accesorios
Componente independiente CartWidget

CartWidget

Componente reutilizable que muestra:

Ícono de carrito mediante react-icons
Cantidad de productos en el carrito (valor hardcodeado para esta etapa)

ItemListContainer

Componente encargado de mostrar un mensaje de bienvenida recibido mediante props.

Footer

Se agregó un componente Footer para completar la estructura visual general del sitio.

Instalación y ejecución

Clonar el repositorio:
git clone URL_DEL_REPOSITORIO

Instalar dependencias:
npm install

Ejecutar el proyecto:
npm run dev

Abrir en el navegador:
http://localhost:5173/
